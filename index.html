Panduan Hubungkan Google Sheets

Anda dapat menjadikan Google Sheets sebagai database gratis tanpa server backend!

  1. Buka Google Sheets baru di sheets.new
  2. Klik menu Extensions → Apps Script
  3. Hapus kode bawaan dan salin (paste) skrip di bawah ini:
  1. Klik tombol Deploy → New deployment (atau Terapkan → Deployment baru).
  2. Pada menu Pilih jenis / Select type (ikon gerigi ⚙️ di kiri atas), pilih:
    👉 Aplikasi web (atau Web app).
  3. Isi konfigurasinya sebagai berikut:
    • Jalankan sebagai / Execute as: Pilih Saya (email Anda) / Me.
    • Yang memiliki akses / Who has access: Wajib pilih Siapa saja / Anyone (agar web dapat mengirim data tanpa login).
  4. Klik tombol Terapkan / Deploy, lalu klik Beri Akses / Authorize access.
    ⚠️ Jika muncul layar "Google hasn't verified this app" (Aplikasi belum diverifikasi):
    Ini normal karena skrip ini Anda buat sendiri di akun Anda. Caranya:
    1. Klik tulisan kecil Advanced (atau Lanjutan) di bagian kiri bawah.
    2. Klik tulisan Go to Project tak berjudul (unsafe) di paling bawah.
    3. Klik tombol biru Allow / Izinkan.
  5. Salin URL Aplikasi Web (Web App URL) yang berakhiran /exec, lalu tempelkan ke kolom input di tombol Google Sheets di pojok kanan atas aplikasi ini.

Pengembangan Modul RumahBudget

Aplikasi ini dibangun menggunakan arsitektur Extensible JS Module.

// Contoh struktur modul baru (js/modules/custom.js)
export const CustomModule = {
  id: 'custom',
  name: 'Kebutuhan Custom',
  icon: 'fa-box',
  renderForm: () => { ... },
  calculate: (inputs) => { ... }
};

Anda dapat menambahkan modul baru di folder js/modules/ tanpa mengubah logika inti aplikasi.
